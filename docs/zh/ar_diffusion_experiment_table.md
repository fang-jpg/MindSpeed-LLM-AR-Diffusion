# AR-Diffusion 简化实验表

## Material Passport

- 研究范围：研究 block size、解码步数、加速比和模型性能

## 1. 一句话说明实验

Diffusion 每次生成一个包含 `B` 个 token 的 block，并用 `S` 次模型前向完成去噪：

- `B` 越大：一次并行生成的 token 越多，理论上越快，但性能可能下降。
- `S` 越少：模型前向次数越少，理论上越快，但性能可能下降。
- 做三档：快速 `S=B/4`、平衡 `S=B/2`、保守 `S=B`。
- 对每一档同时记录真实速度和 GSM8K 性能，最后选 3 个配置做五任务评测。

### 如何看这张表

1. 同一档位向下看，例如比较 `B04-S01、B08-S02、B16-S04、B32-S08`，观察 block 变大后的速度和性能变化。
2. 同一 block 横向看三档，例如比较 `B16-S04、B16-S08、B16-S16`，观察增加去噪步数能恢复多少性能、损失多少速度。
3. 先排除 `Speedup <= 1` 的配置，再在剩余配置中找 GSM8K 下降最小的点。

## 9. 一次性代码确认，不算实验

`from_pretrained` 中 embedding 拷贝到 `lm_head` 是否正确，取决于加载的 checkpoint：

- 第一次从 Base 模型初始化，且 Base checkpoint 没有兼容的 `lm_head.weight` 时，复制是合理的初始化方法。
- 加载已经完成 joint CPT 的 checkpoint，且 checkpoint 中保存了训练后的 `lm_head.weight` 时，再复制会覆盖训练结果，此时不合理。
